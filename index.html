테스트 방법
  • 정면을 보다가 고개를 좌우로 돌려 정면 유지 추정 값이 변하는지 확인
  • 화면 바깥을 바라보며 시선 안정도 추정 값이 변하는지 확인
  • 눈을 감거나 몇 번 깜빡여 눈 감김 정도 값이 반응하는지 확인
  • 얼굴을 프레임 밖으로 빼서 얼굴 감지가 0으로 떨어지는지 확인
